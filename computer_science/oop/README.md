# Object-Oriented Programming (OOP) & Design Curriculum

Welcome to the comprehensive OOP and System Design curriculum. This course is designed to take you from the fundamental principles of Object-Oriented Programming all the way to passing rigorous Object-Oriented Design (OOD) rounds in top-tier Software Development Engineer (SDE) interviews.

## Who is this for?
- Aspiring and current Software Engineers (SDEs) preparing for technical interviews.
- Backend Engineers looking to write cleaner, more maintainable, and scalable enterprise code.
- Anyone looking to deeply understand how memory, classes, and inheritance work under the hood.

## Language Strategy
We take a dual-language approach to maximize your understanding:
- **C++:** Used in the early modules to explore memory management, vtables, pointers, and how polymorphism actually works under the hood.
- **Java:** Used heavily in the design patterns and interview modules because of its idiomatic OOP features, rich standard library, and dominance in enterprise backend systems.

## Suggested Study Order & Time Estimates

To get the most out of this curriculum, follow this linear progression:

1. **Phase 1: The Core (M1 - M3)**
   - *Time:* 2-3 days per module.
   - *Goal:* Build an unshakable foundation in memory mechanics and the four pillars of OOP.
2. **Phase 2: Enterprise Architecture (M4 - M7)**
   - *Time:* 3-4 days per module.
   - *Goal:* Learn *how* to combine the pillars to write clean code (SOLID) and solve recurring problems (Patterns).
3. **Phase 3: The Interview (M8)**
   - *Time:* 1 week minimum.
   - *Goal:* Apply everything you've learned. Practice on whiteboards or paper. Do not just read the solutions.

## How to Use This Curriculum

For every module in this repository, follow this workflow:
1. **Read the `README.md`:** This contains the core instructional material, diagrams, and code snippets.
2. **Test yourself with `QnA.md`:** Attempt to answer the Easy, Medium, and Hard questions before looking at the answers.
3. **Review the `CHEATSHEET.md`:** Keep this open on a second monitor while practicing, or use it for rapid review the week of your interview.

## Prerequisites
To succeed in this curriculum, you should have:
- Basic programming knowledge (variables, loops, functions, basic data structures).
- A preliminary understanding of what a "class" and an "object" is in any programming language (Python, JS, C++, or Java).
- A local development environment capable of compiling Java and C++ code.
